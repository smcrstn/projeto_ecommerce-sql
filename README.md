# 📊 Projeto E-commerce SQL

## 🎯 Objetivo
Desenvolver um banco de dados relacional para simular operações de um e-commerce, com foco em pedidos, clientes e entregas.

## 🧱 Estrutura do Banco
- Cliente
- Pedido
- Entrega

## 🔗 Relacionamentos
- Um cliente pode fazer vários pedidos
- Cada pedido pode ter uma entrega associada

## 📊 Análises realizadas
- Listagem de pedidos com status de entrega
- Identificação de pedidos sem entrega
- Contagem por status de entrega
- Classificação de pedidos (Finalizado/Pendente)

## 🛠 Tecnologias
- MySQL

## 📁 Arquivos do projeto
- script.sql → Estrutura + dados + queries
- diagrama.pdf → Modelo lógico do banco
